> **Verifiable Brand Compliance & Cryptographic Content Passporting**  
> 🌐 **Live Website**: [https://verifibrand-9h26.vercel.app/](https://verifibrand-9h26.vercel.app/)  
> Full architectural documentation is located in the root [README.md](../README.md).

---

### Quickstart

1. **Install dependencies**:
   ```bash
   cd frontend
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Open in browser**:
   - Direct: [http://localhost:3000](http://localhost:3000)
   - Windows PowerShell: `Start-Process http://localhost:3000`
