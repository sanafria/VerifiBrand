# BrandLedger Frontend Documentation

The comprehensive, authoritative BrandLedger project documentation (architecture, setup, testing, API reference, and 3-minute hackathon demo script) is centralized in the root [README.md](../README.md).

### Quickstart

1. **Start the development server**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

2. **Open localhost in your browser**:
   - **Direct URL**: [http://localhost:3000](http://localhost:3000)
   - **Windows (PowerShell)**:
     ```powershell
     Start-Process http://localhost:3000
     ```
   - **macOS**:
     ```bash
     open http://localhost:3000
     ```
   - **Linux**:
     ```bash
     xdg-open http://localhost:3000
     ```
